# 发布与推广手册

> 目标：让「GH2 中文操作库」成为中文参数化用户查 GH2 电池时的第一站。
> 原则：**先给价值，再求关注**。每条帖子里必须有能直接用的东西（一个组件解读、一次识别演示），而不是纯链接。

站点：<https://coderong9.github.io/gh2-cn-reference/>
仓库：<https://github.com/codeRong9/gh2-cn-reference>

## 一句话定位（各平台统一口径）

- 短版：**Grasshopper 2 的每个电池，这里都有中文说明。**
- 长版：GH2 的帮助面板只有英文。这个站把 1516 个组件与参数对象逐条译成中文，写清端口吃什么、怎么连、什么时候用，还能粘贴组件代号直接认出画布里的电池。

## 发布节奏

- **Day 0**：GitHub Release + 中英 README 互链 + 自己群里首发
- **Day 2**：B 站/小红书各一条，知乎回答一条
- **Day 7**：根据反馈补 3–5 个被问最多的组件精讲，再发一条「应你们要求补了 XX」——二次曝光比第一次更高
- **长期**：每补一批精讲就发一次更新，标题用「这次补了你们要的 XX」

## 雷区

1. **不要复制 McNeel 的图标去打商业广告**：站点已声明非官方、图标版权归 McNeel，推广文案别写「官方中文版」
2. **不要在同一个群反复刷**：一次首发 + 一次更新足够
3. **不要把「猜」当卖点**：所有释义都有出处，遇到质疑直接给程序和原文
4. **评论区必须回**：前 50 条评论决定这个项目在社区里的口碑
