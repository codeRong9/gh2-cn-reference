# 01 · Brief — GH2 中文操作库 宣传片

## 产品定位
Grasshopper 2（Rhino 9 自带）的中文参考站：1516 个组件与参数对象全量中文速查 + 171 篇精讲 + 画布/代号识别台。

**一句话**：把 GH2 的每个电池讲成中文。

## 目标观众
- 中文参数化 / 建筑 / 工业设计用户，受困于 GH2 英文帮助面板
- 刚入门、查电池靠猜的初学者（核心人群）

## 核心卖点 + 证明点
| 卖点 | 证明点（真材实料） |
|---|---|
| 全量覆盖 | 1516 对象 / 15 库 / 6070 端口 / 171 篇精讲 |
| 不是截图堆砌 | 数据从 GH2 程序集反编译而来，与帮助面板同源 |
| 真能查到 | 中英名 / 拼音 / 别名检索，Ctrl+K 命令面板 |
| 识别台 | 粘贴组件代号 `00000000-a9e2-…` 直接出中文 |
| 免费开源 | GitHub 公开 + MIT（代码/原创中文） |

## 推荐视觉风格
**Clean UI Demo**（真实软件界面优先）——白底蓝图网格 + 单一强调绿 `#2F9E5F`，等宽字体做「代号」元素。
不要氛围片、不要 AI 大场面；把「查一个电池」这件事拍清楚。

## 叙事结构（60–75s）
Hook 数据冲击 → 痛点（英文面板）→ 产品登场（真实界面）→ 检索能力 → 识别台（代号高光）→ 开源/反馈 CTA

## 时长建议
75s（可剪 60s 短版，Hook 与 CTA 不变）

## 风险 / 素材缺口

- 渲染依赖 HyperFrames（浏览器 + ffmpeg），本机缺 ffmpeg/Chrome，见 05-delivery
